# GLPI Impact Builder

Proyecto Open Source para automatizar la construcción y sincronización de mapas de impacto en GLPI Community, Enterprise y Cloud.

## Objetivos

- SDK Python para GLPI Impact
- Compatibilidad con GLPI Cloud y On-Premise
- Importación desde Excel/CSV
- Automatización mediante Playwright y API REST
- CLI y GUI
